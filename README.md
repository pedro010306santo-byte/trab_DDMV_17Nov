# Lista de compras

Aplicativo Android em Kotlin para a atividade de DDM de 17 de novembro.

Digite o nome da lista, marque os itens, escolha uma prioridade e toque em **Enviar**. O botão **Ver segunda tela** mostra o mesmo resumo em outra tela.

Para executar, abra esta pasta no Android Studio, sincronize o Gradle e rode o módulo **app** em um dispositivo ou emulador Android.

O [vídeo de demonstração](Ativ17Nov_Demonstracao.mp4) também está neste repositório. Ele mostra o preenchimento da lista, o resultado e a passagem para a segunda tela.
