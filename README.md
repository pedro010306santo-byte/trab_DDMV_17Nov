# Atividade de DDM — 17 de novembro

**Aluno:** Pedro Henrique do Santo

**Tema:** Lista de compras

Aplicativo Android em Kotlin para montar uma lista de compras e definir a prioridade. O botão **Enviar** mostra o resumo e **Ver segunda tela** abre o mesmo resultado em outra tela.

## Arquivos da atividade

- [Projeto Android Studio em ZIP](PedroSanto_NomeDupla_Ativ17Nov.zip)
- [PDF com a descrição do tema](Ativ17Nov_Lista_de_Compras.pdf)
- [Vídeo de demonstração](Ativ17Nov_Demonstracao.mp4) — mostra o preenchimento do formulário, o resultado e a passagem para a segunda tela.

Para executar o código do repositório, abra esta pasta no Android Studio, sincronize o Gradle e rode o módulo **app** em um dispositivo ou emulador Android.
